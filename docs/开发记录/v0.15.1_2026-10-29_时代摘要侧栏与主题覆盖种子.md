## 2. 任务目标

**A. 恢复时代摘要（来源：线上反馈 + v0.8.0 改版遗留）**

v0.8.0 把公共站拆成三套独立版式后，年份标题右侧只剩 `era.title` 一句话（`EditorialView.tsx:658`、`AuroraView.tsx:527`、`MuseumView.tsx:623`），原来单主题版本右侧那整段时代概述（`era.text`）不再出现在任何位置。目标：桌面端恢复为随滚动切换的「时代摘要」侧栏，窄屏折叠到年份标题下，三套版式各自配色。

**B. 主题覆盖审计阶段一（来源：`docs/AI纪年_主题覆盖审计_2026-10-29.md` 第 8 节）**

审计结论是「机器学习缺入口、智能体缺节点」：种子侧 `机器学习` 标签 0 条；`智能体` 标签 38 条（线上 168 条口径）绝大多数是「某模型具备智能体能力」，Manus / WorkBuddy / OpenClaw 均为 0 条，`Muse` 只命中 Meta 的多模态模型。阶段一按批准范围只做「内容补录 + 覆盖基准」，不改类别、不改管线、不改标准。

**本次迭代环节的边界**：只写迭代记录 + 升产品版本三处 + 跑 `check-version`。不修改 `backend/app/data/seed.json` 与 golden（生成物）、不动 UI 代码、不提交 Git。

## 4. 方案与实施

### 4.1 核心取舍

1. **一份组件、三处传参，而不是三份复制**。`EraBrief`（桌面吸顶栏）与 `EraNote`（窄屏折叠）是唯一实现，三套版式只传 `variant`（`editorial` / `aurora` / `museum`）。配色、字号、落点差异全部收敛在组件的 `shell` / `head` / `body` / `LABEL` 四张表里。
2. **`eraSpan` 由 `ERAS` 派生，不新增数据字段**。`ERAS` 是倒序、相邻区间首尾相接，区间上界取 `ERAS[index - 1].from - 1`；最老的一段回退为「`from` 年至今」。这样区间永远与分带定义一致，不会出现「`from` 与新增的 `to` 互相矛盾」。
3. **`activeYear` 改为「吸顶线判定」，不再用 `IntersectionObserver`**。取最后一个 `top <= 160px` 的 `[data-year]` section 即为当前年份；`scroll` 走 `requestAnimationFrame` 合并（同一帧只算一次），`resize` 复用同一调度，卸载时 `cancelAnimationFrame` 并移除两个监听。
4. **内容侧只加种子与基准**。审计阶段一的约定是「内容与门槛分开走」：这次不动 `category` 枚举、不动 `classify_title`、不动收录标准，避免同一提交里既有内容变化又有语义变化，事后无法判断是哪一侧让覆盖率或门槛结论变动的。

### 4.3 关键实现细节

- **侧栏落点**：三套版式都把右列放在「时间轴结果区」的外层栅格上，而不是塞进某个 YearBlock。这样主列里原有的收尾区块（典藏的「档案到此为止」卡、极光的订阅 CTA、博物馆的 `mu-green` 绿色条）仍留在左列末尾，侧栏永远在视口右侧独立吸顶，不随筛选结果数量变化而错位。
- **粘性偏移按版式给**：`editorial` `top-[8.75rem]`、`aurora` `top-[6.5rem]`、`museum` `top-[9rem]`——三套版式的顶部导航与工具条高度不同，统一值会让侧栏被顶栏压住一截。
- **主列 `min-w-0`**：栅格子项默认 `min-width: auto`，条目里的长标题/长 URL 会把 `1fr` 撑破并挤出横向滚动条；`min-w-0` 是这条栅格能成立的前提。
- **窄屏**：右列整体 `hidden lg:block`，不渲染也不占位；每个年份标题下插 `<EraNote>`，用原生 `<details>/<summary>`（`lg:hidden`、隐藏 `::-webkit-details-marker`、`＋` 号 `group-open:rotate-45`），折叠态摘要行是「时代特征 · 区间 · 标题」，展开后是带左实线边的 `era.text` 全文。用 `<details>` 而不是受控 state，是为了不引入额外重渲染、也不打断键盘与读屏的原生语义。
- **低谷期样式**：`era.kind === "winter"`（如 1987—1996）标题文案改为「低谷期」，正文段落加 `border-l-2 border-dashed`。本地 1987 截图（`temp/era-shots/editorial-1987.png`）确认虚线样式与常规期区分明显。
- **`activeYear` 初值**：`useArchive` 里 `activeYear` 仍可为 `null`，视图侧传 `activeYear ?? groups[0].year` 兜底；早于第一个分组可见时不会闪空栏。筛选变化会导致当前年份不在 `groups` 中，既有逻辑（`useArchive.ts:163`）把它重置为 `null`。
- **种子写法**：14 条全部走 `functions/lib/seed.mjs` 的 `seed()` 家族，证据用一手来源（论文 / 官方公告 / GitHub 仓库）；智能体条目归入既有 `milestone` / `research`，不新建类别；2026 年三条（`openclaw-2026`、`workbuddy-2026`、`muse-agent-2026`）importance 控制在 84–86 且 `note` 标注「历史地位待时间检验」；`Muse` 智能体用 `muse-agent-2026` 与既有 Muse 多模态模型区分 `seedId` 与标题。
- **benchmark 断言**：14 条 `b()` 用 `phrase` 匹配标题原文（「Q-learning」「随机森林」「变分自编码器」「图卷积网络」「Scaling Laws」「DDPM」「推理—行动」「AutoGPT」「Model Context Protocol」「Manus 发布」「终端编程智能体」「OpenClaw」「WorkBuddy」「个人智能体 Muse」），不引入新的匹配机制。
- **标签效果**：种子侧 `机器学习` 0 → 6、`智能体` 27 → 35、`深度学习` 3 → 6、`强化学习` 6 → 7、`神经网络` 8 → 9（按 `seed.json` 的 `tags` 统计）。审计指出的「`机器学习` 一条都没有」在数据层被消除，但**筛选入口仍未提供**（属阶段二）。

**被否决的方案**

- **把 `era.text` 直接放回年份标题下（三套版式都放）**：每个 YearBlock 会被撑成一整段，时间轴密度和扫读节奏都会被破坏；窄屏有折叠需求，宽屏没有——最终只在 `lg` 以下用 `EraNote`，宽屏走侧栏。
- **抽一个共享的 `EraRail` 包住三套版式的两列栅格**：三套版式主列尾部区块（结束卡 / CTA / 绿色条）的结构、间距、配色各不相同，共享外层只能靠 `children` 透传加一堆 `className` 覆盖，耦合比现在传一个 `variant` 更高。
- **给 `ERAS` 增加 `to` 字段承载区间**：`ERAS` 是倒序、区间首尾相接，派生比多一个需要人工维护且可能与 `from` 矛盾的字段安全。
- **继续用 `IntersectionObserver`，只调 `rootMargin`**：滞后是「取 top 最小者」这条规则导致的，任何 `rootMargin` 只能把边界挪几行，不能消除；而且它衡量的是「可见性」而不是「读者位置」。
- **`scroll` 事件里直接 `setActiveYear`**：一次滚动几十个事件，等于每帧一次全量重渲染；`requestAnimationFrame` 合并后每帧最多一次。
- **把 14 条种子拆到下一个版本单独发**：内容与测试/夹具已经是一致状态，拆开会让 172 这个数字在两次发布之间处在「测试与夹具已改、版本号未跟」的中间态；而且阶段一的门禁已整体跑通一次。
- **放宽 golden 里的计数断言（例如只校验键名不校验 `total`）**：计数与 digest 正是这次要冻结的东西，放宽等于把契约变成橡皮筋；正确做法是重导夹具、保留严格断言。
