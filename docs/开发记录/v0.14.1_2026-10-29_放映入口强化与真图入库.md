## 2. 任务目标

两条线上反馈，一条承接 v0.14.0 的遗留：

1. 「右下角 自动演示 悬浮按钮不够显眼突出」——入口存在，但在首屏的留白里几乎看不见。
2. 「能否再通过检索下载一些历史事件的高质量配图」——v0.14.0 只落了配图的第一层（14 张 AI 生成示意图），第 11 节把「换成有出处的真图」写成了下一步。

## 3. 问题诊断

| 现象 | 原因 |
| --- | --- |
| 悬浮按钮不突出 | `.show-launcher` 用纸色 90% 半透明底 + 1px 描边、42px 高、13px 字，视觉权重与页面其他次级按钮同级；滚动到任意位置都与背景同色，只有描边勾出轮廓 |
| 真图缺位 | `visuals.json` 里 14 条全是 `kind: "illustration"`，标注「非史实照片」——诚实，但档案的史料感被打了折 |
| 图版少一层且控制台报错 | `VisualPlate` 两处半径写成「起点 − 序号 × 步长」，`rings` 取 4–7；取 7 时最内层算出负数（轨道 `rx = -12`、光阑 `width = -8`），SVG 判为非法属性直接吞掉那一环，约四分之一的 `research` / `model` 图版一直少一层，同时每次渲染都往控制台丢两条 error |

第三条不在原始需求里，是逐屏验收时被控制台日志抓出来的。

## 4. 方案与实施

### 4.1 入口：反白实底 + 一次性提醒

| 决定 | 理由 |
| --- | --- |
| 用 `--ink` 底 + `--paper` 字 | 三套主题下这两个令牌互为反转色，对比度恒定最高，不用为极光写第二套颜色 |
| 34px 强调色圆徽标（`--accent-mark`）+ 双行文案「自动演示 / 一屏一条 · 可分享」 | 圆徽给了一眼可辨的形状，副标题说明了它是什么，而不是等用户点开才懂 |
| 条数胶囊 | `show.count` 直接报「有多少条」，把「值不值得点」提前回答 |
| 三层阴影 + 1px 强调色发丝环 | 在纸色与近黑两种底上都能「浮」起来，不依赖背景色 |
| 3.4s 外扩呼吸环，**用过即安静** | 显眼是第一眼的义务，不该变成常驻噪声；写入 `localStorage["aihist.show.seen"]`，之后连 `::after` 一起关掉 |
| `prefers-reduced-motion: reduce` 全关 | 呼吸环与 hover 位移都属于装饰 |
| 窄屏 48px 高、12px 圆角、隐藏副标题与条数 | 390 宽下 `scrollWidth = 390`，不溢出 |

被否决的：只加阴影或放大字号（与页面其他按钮的区别仍然不够）；常驻脉动（时间一长就是噪声，且分散正文注意力）。

### 4.2 检索：只收能核到文件页的图

Wikimedia Commons 官方 API（`generator=search` + `gsrnamespace=6`，`prop=imageinfo&iiprop=url|size|mime|extmetadata&iiurlwidth=1400`），分三批共 35 组关键词。授权只认 API 返回的 `LicenseShortName`，白名单 `CC0 / Public domain / CC BY 2.0·3.0·4.0 / CC BY-SA 2.0·3.0·4.0`；候选下载后逐张看过再定，淘汰的是构图而不是分辨率：Roomba 站在门边、Deep Blue 的展牌占去半幅、欧洲议会官网图只有会场仰拍的天花板、CC0 博物馆展品照偏暗且反光。

### 4.4 登记表新增两个字段

| 字段 | 用途 |
| --- | --- |
| `sourceUrl` | 指回 Commons 文件页；图注末尾渲染成「原图 ↗」外链，CC BY / CC BY-SA 的署名与可追溯要求都在这一行兑现 |
| `fit: "contain"` | 给「宁可留白也不能裁」的横构图。留白交给 CSS 的 `--plate-bg`，而不是把纸色烤进 JPEG——早先 `el-ajedrecista-1912` 用 PowerShell 补了纸色边，在极光主题下就是一大块亮斑 |

图注因此变成 `署名 · 授权 · 原图 ↗`。空格键原本在放映里是暂停/继续，焦点落在链接上时改为交给浏览器（`closest("a")` 提前返回），否则想用键盘打开来源的人会先把演示停掉。

### 4.5 图版负半径

改成按环数收紧间距：轨道 `min(44, 220 / (rings - 1))`、光阑 `min(30, 212 / (rings + 1))`；四到六环维持原样，只有七环收紧。同一 slug 的图版仍然确定性可复现。

### 4.6 体积

12 张 1400px 缩略图转成 900 宽 JPEG（质量 88，`System.Drawing`，无 Pillow）：裁切按焦点、横构图只缩不裁。`public/visuals` 现 23 张共 3612 KB，其中 12 张真图 2148 KB。

## 7. 发布与回滚

- **静态站**：`git push origin main` 后由 Vercel 自动构建部署；核对以「线上 HTML 引用的 assets 哈希 == 本地 `dist` 引用」为证，再抽查 `/visuals/*.jpg` 与一次线上 CDP 放映。
- **API 服务器**：本轮无后端代码与迁移变更，`D:\srv\aihist` 不执行 `git pull` / `Restart-Service`。`/api/v1/status` 不含产品版本，线上 API 行为不变；部署副本里 editable 安装的版本元数据仍在下次后端发版执行 `pip install -e backend --no-deps` 时随 `pyproject.toml` 更新。
- **回滚**：`git revert` 本次提交即可；图片是纯静态资源，无数据迁移，无缓存需要清理。SQLite 未写入，无需备份。

## 11. 总结

这一轮把放映从「能用」推到「愿意点」：入口靠反白实底与圆徽在第一眼拿到注意力，用一次就安静，不再持续干扰；配图从「14 张示意图」变成「12 张有出处、可授权、图注可点回原文件页的真图 + 11 张标清楚的示意图」，剩下的一百多条继续用确定性图版顶上。顺带修掉的负半径 bug 说明图版这条兜底链一直在静默少画一层——它也提醒：兜底路径同样要进控制台验收。
