## 2. 任务目标

`/admin` 是独立 bundle，未登录时整页只渲染 `LoginPane`。此前这张卡片从上到下是「运营控制台」标题、一句说明、账号／密码、登录按钮——**看不出这是哪个站点，也没有回到公共站的出口**。上线后凡是拿到后台地址、或被分享 `/admin` 链接的人，都会停在这一屏：要么有凭据、要么只能手改地址栏或按浏览器后退。

目标两件事：

1. 登录卡片顶部给出**可识别的站点标识**（图形 + 中英文名），并且标识本身就是回到 `/` 的入口；
2. 表单下方再给一个**明确的次级出口**「返回网站首页」，让不打算登录的人不必猜。

**本次迭代环节的边界**：只写迭代记录 + 升产品版本三处 + 跑 `check-version`。不改 UI 代码、不动 `seed.json` 与 golden（生成物）、不跑 `release-gate`、不提交 Git。

## 3. 问题诊断

| 现象 | 原因 |
| --- | --- |
| 登录页只有「运营控制台」标题与凭据表单，读者无法确认自己在哪个站点 | `/admin` 是独立 bundle（`admin.html` → `src/admin/main.tsx`），公共站的 `SiteHeader` / 三套版式都不在这棵渲染树里；`LoginPane` 此前只承担认证职责，顶部没有任何品牌位 |
| 已登录后有顶栏，未登录时一个出口都没有，只能手输地址或后退 | 回公共站的入口挂在**已登录导航**上，会话建立前该组件不渲染；而整页唯一的未登录界面 `LoginPane` 从未提供出口 |
| 直接复用 `BrandMark` 时，第三片简会渲染成公共站的铜色，与深色控制台的强调色不是一套 | `--accent-mark` 定义在 `src/globals.css` 的公共站调色板里（纸本 `#a67c3d`、极光 `#a98bff`、博物馆 `#b08d4f`）。`src/admin/theme.css` 的 `:root` 别名区只重映射了 `--paper` / `--ink` / `--accent` 等旧名，**没有重映射 `--accent-mark`**，于是公共站纸本的装饰色漏进了控制台的两套主题 |
| 登录页只有 384px 宽的卡片，加两行内容后窄屏容易溢出的风险 | 卡片是 `max-w-sm`（24rem = 384px），外层 `px-5 py-16`；在 390 宽视口下可用宽度只有 350px，lockup 里「AI 纪年」+「首页 ↗」是同一行的两端，没有 `min-w-0` 就会被长字挤出去 |

## 4. 方案与实施

### 4.1 核心取舍

1. **复用 `BrandMark`，不自绘 logo**。`BrandMark` 的约定是「所有颜色都是主题 token」，一份几何同时服务公共站三套版式与页脚。30px 落在 `MICRO` 档（`size < 32`）：只画四片简、不做走线与穿孔，第三片（`accentIndex: 2`）取 `--accent-mark`——在这个尺寸下四片简才读得出「简」，加走线会糊成栅栏。
2. **品牌 lockup 本身就是首页入口**（一个 `<a href="/">` 包住图形 + 双行文字），而不是「标识 + 旁边一个图标按钮」。少一个可点目标，且「看不出来自己在哪」这个场景里，最自然的动作就是点那个标识。
3. **第二个出口做成整宽次级按钮，并用「或」分隔线在视觉上与凭据分开**。登录是主操作（accent 实心按钮），回首页是次要出口，不能抢主操作的视觉权重；它服务的对象是「没打算登录、只是想看看公共站」的人，所以必须落在表单下方、语义上独立于表单。
4. **强调色跟随控制台主题，而不是给组件加 prop**。在 `src/admin/theme.css` 的 `:root` 别名区补一行 `--accent-mark: var(--c-accent)`，写在只重映射一次的别名块里，两套主题各自解析，`BrandMark` 与 `globals.css` 都不用改。

**被否决的方案**

- **在卡片右上角放「返回首页」小链接**：右上角已经被深/浅主题切换按钮占住（`LoginPane.tsx:80`–`87`），再加一个同权重的小链接会变成两个相邻的角标按钮，且小链接在 390 宽下会被主题按钮挤到视觉死角。
- **给 `BrandMark` 加一个「第三片用什么颜色」的 prop**：`BrandMark` 的契约是颜色全部走 token；加 prop 等于为 admin 这一个使用点开分支，下一处复用又要再决定一次。改一个 CSS 别名是最小的语义修正。
- **用 `react-router` 的 `Link` 做跳转**：公共站与运营台是两个独立 HTML 入口（`index.html` / `admin.html`），SPA 内导航不成立，必须整页跳转，因此是普通 `<a href="/">`。
- **把公共站 `SiteHeader` 直接搬进登录页**：它依赖公共站的三套版式切换与那一整套 token，带进 admin bundle 会同时引入公共站主题体系与多余依赖，和「admin 与前台解耦」的既有设计相反。
- **把「返回网站首页」放在登录按钮上方**：会打断「账号 → 密码 → 登录」的视觉流，主操作被次级出口隔开，反而更容易点错。
- **在 lockup 右侧也用 `--c-accent` 常亮提示**：常亮会把次要提示抬成第三个强调元素；现在只在 hover 时转强调色，静态下是 `--c-text-mute`。

### 4.3 关键实现细节

- **lockup 结构**：`className="group -m-1 flex items-center gap-2.5 rounded-[var(--c-radius)] p-1"`。`-m-1` + `p-1` 让可点热区比视觉边界外扩 4px，同时不改变卡片内的布局节奏；`group` 供内部两处 hover 变色使用。
- **两处 hover 分级**：副行 `AI Chronicle · Console` 由 `--c-text-mute` → `--c-text-dim`（只是变清楚一档）；右侧「首页 ↗」由 `--c-text-mute` → `--c-accent`（唯一的强调反馈）。两者都走 `transition-colors`，不做位移。
- **右侧提示 `aria-hidden="true"`**：链接本身已有 `aria-label="返回 AI 纪年网站首页"` 与 `title`，若「首页 ↗」也进无障碍树，读屏会念成「返回 AI 纪年网站首页 首页」，重复且含符号。
- **`min-w-0`**：lockup 中间的文字块是 `min-w-0`，右提示是 `ml-auto`——390 宽下「AI 纪年」与「首页 ↗」分列两端，副行过长时被压缩而不是撑破卡片。
- **分隔线**：`mt-5 flex items-center gap-2.5`，两侧 `h-px flex-1 bg-[var(--c-line)]`，中间「或」为 9px 等宽大写；整块 `aria-hidden="true"`——纯装饰，读屏不需要念这个「或」。
- **次级按钮**：`mt-3 flex w-full items-center justify-center gap-2` + `border-[var(--c-line-strong)] bg-[var(--c-surface-2)]`，与登录按钮（`bg-[var(--c-accent)]` 实心）形成主次对比；hover 时 `border` 与 `text` 同时转 `--c-accent`。箭头 `←` 包在 `aria-hidden` 的 span 里，语义由文字「返回网站首页」承担。
- **`--accent-mark` 落在别名块而非主题块**：`src/admin/theme.css` 的 `:root` 别名区只写一次，靠 `var(--c-accent)` 在深/浅两套调色板上各自求值；若写进 `[data-theme="dark"]` / `[data-theme="light"]` 两张表，就得维护两行同义声明，也违背该文件「one file controls the whole surface」的注释约定。
- **不动 `globals.css`**：`--accent-mark` 在公共站被 `EraBrief`、`FooterSites`、`.brand-mark` 的边框与 `--chart-1` 等多处引用，改它等于改三套公共版式；正确方向是让控制台在自己的作用域内覆盖。
- **尺寸选择**：30px 既够认出四片简，又不会在 384px 卡片里压过「AI 纪年」的中文标题（16px）；与公共站页脚 micro 档一致，视觉上是同一个标记的同一档刻画。

## 11. 总结

一张登录卡片从「只有凭据、看不出自己在哪」变成「先自报家门、再给出口」：顶部换成由 `BrandMark` 30px（third slip 取控制台强调色）加中英文名组成的品牌 lockup，整块就是回 `/` 的链接，并在右侧用 hover 才转强调色的「首页 ↗」作为提示；表单下方用一条「或」分隔线把主操作（登录）与次级出口（返回网站首页）分开，让「只是路过、并不想登录」的人也有一个明确可点的去处。代价被压到最小：只动三个文件、源码净增 48 行（`LoginPane.tsx` +46/−2、`theme.css` +4），登录流程、会话、权限、接口、数据库一层都没碰，`RUBRIC_VERSION` 与 `SEED_VERSION` 原地不动，`seed.json` 与 golden 一个字节没重导，静态页仍是 172 个、sitemap 仍是 173 条——这次唯一的契约性变化是 `src/admin/theme.css` 多了一个 `--accent-mark` 别名，把「公共站纸本铜色漏进控制台」这个隐患在自己的作用域里关掉，而不是去改被三套公共版式共用的 `globals.css`。真正值得记住的是它的来路：admin 是独立 bundle，任何「公共站顺手就有」的东西都不会自动出现，需要一处一处补，这次补的是最靠前的第一屏。
