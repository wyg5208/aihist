## 二、任务目标

1. **先回答「外源能不能借」**。用户给出 `open_resources/AIHistoryTimeline`（Targoman 的 AI 历史长图），要求判断能否借鉴到 AI 纪年。结论：可以作为**缺口检查表**与**叙事编排参考**，不能作为数据源与素材源。
2. **第 1 步：把经典期的洞补上**。海报清单与本仓库种子逐条比对后，选出 10 条本项目缺失、且能找到一手来源的事件入档，同时保证覆盖率门禁不回退。
3. **第 2 步：让「两次寒冬」在时间线上看得见**。`ERAS` 把 1950–1996 压成一个时代，侧栏在 1974 与 1987 两个低谷期都显示同一句概括。
4. **重启上线**：把新种子写进运行库，重启 API 与前端，确认线上读到的就是 158 条。

## 三、问题诊断

### 1. 时间线的时间分布严重偏斜

| 现象 | 原因 |
|---|---|
| 148 条里 2020 年之后 95 条，1912–1949 只有 7 条，1980–1996 只有 5 条 | 种子历史以「模型发布 + 近期产业事件」为主，经典期靠零散补录，没有按时代做均衡 |
| 覆盖率检查里 `1980s` 长期存在缺口（`xcon-1980` 在 benchmark 有、archive 无） | benchmark 是按「严肃编年史应该有什么」写的，archive 是实际入库量，两者之间的差额就是这类缺口 |

补录前分布：`pre-1950 7 / 1950–1979 18 / 1980–1996 5 / 1997–2012 9 / 2013–2019 14 / 2020+ 95`。补录后：`9 / 19 / 8 / 11 / 16 / 95`。

### 2. 1950–1996 被压成一个时代

| 现象 | 原因 |
|---|---|
| 定位到 1966、1974、1987 任意一年，侧栏都显示同一段「从图灵测试到达特茅斯会议……在两次热潮与寒冬之间前行」 | `ERAS` 只有 10 段，`from: 1950` 的那一段一直延伸到 1996，两次寒冬被折叠成一句概括 |
| 时间线上看不出第一次低谷与专家系统繁荣的界线 | 缺 1974 / 1987 两个分界点；`Era` 也没有字段表达「这一段是盛还是衰」，前端只能一律当正面叙事渲染 |

### 3. 外源海报只能当清单，不能当数据

| 海报标注 | 实际 | 判断 |
|---|---|---|
| 1900 三极管 | de Forest 的 Audion 是 1906（专利 1907） | 年份错 |
| WABOT-2 1980 | 1984 完成 | 年份错 |
| RoboCup 1996 | 首届是 1997 名古屋（1996 只有 Pre-RoboCup 表演赛） | 年份错 |
| WaveNet 2017 | arXiv 提交于 2016-09 | 年份错 |
| Blue Brain 2008 | 项目 2005 年启动 | 年份错 |

海报是一张 Inkscape 手绘 SVG（501×335mm），40 个左右事件全部是图上的 `<text>` 节点，没有数据文件、没有引用、没有日期精度。五处硬伤说明它连「年份」这一层都不能直接采信。**MIT 许可只覆盖图本身，18 张第三方配图不在其中**，所以素材也不能搬。可借的只有两样：缺口清单（哪些事件该项目有而我们没有）与叙事编排（时代分带 + 两次寒冬）。

### 4. 覆盖率门禁与重要度的耦合

| 现象 | 原因 |
|---|---|
| 新增重要度 ≥ 85 的种子会直接让 G5 变红 | `scripts/coverage.mjs` 要求 `curatedImportance >= 85` 的每一条种子都能在 `scripts/benchmark.mjs` 里匹配到条目，否则报 `high-importance seed has no benchmark entry` |
| DQN 的 `importance` 定为 86 | 2015 年 Nature 封面 + 深度强化学习起点，量化口径下就是 ≥85 的一档，于是必须同时登记基准条目 |

## 四、方案与实施

### 4.1 核心取舍

**补录的准入线是「能解析到一手来源」，不是「海报上有」。** 先把 40 条清单按年份排出候选池，再逐条实测：DOI 走 `api.crossref.org` 解析、官方域名直接打 HTTP、arXiv 用 abs 页。11 条通过、5 条放弃。放弃的 5 条不是不重要，而是拿不到可核验的落地页——把它们写进档案，等于在一份标注「单一权威来源」的条目里放一个我打不开的链接。

**宁可少一条，也不给来源降级。** 《控制论》原书（1948，MIT Press）是这条线上最该有的条目，但 `mitpress.mit.edu` 对脚本请求返回 403，`openlibrary.org` 在本机不可达。于是换成同一思想的可核版本：Wiener、Bigelow、Rosenblueth 1943 年发在 *Philosophy of Science* 的《Behavior, Purpose and Teleology》，DOI `10.1086/286788` 能解析。条目讲的是「控制论纲领成形」，不是「一本书出版」，叙事上更准确。

**时代分带沿用既有数据结构，不为一次展示改动引入区间模型。** `ERAS` 是倒序数组 + `find(year >= from)`，加分段只是在数组里插元素；改成 `{from, to}` 区间会同时影响 `eraFor` 与 `SideRail` 的 `upper` 计算，收益为零。

**1973 年莱特希尔报告留在「学科诞生」，低谷从 1974 起。** 报告 1973 年发表，经费收缩是 1974 年才落到项目与人员上的；这样切，`MYCIN`（1974）正好落在低谷段的第一条，条目与时代语境互证。这是一处可争议的边界，已在 `eras.ts` 与本文都写明，改成 1973 只需要动一个 `from`。

**摘要措辞要避开关键词推断的雷区。** `functions/lib/keywords.mjs` 的 `RULES` 会从 title / summary 里推 tag，`风险` 命中「安全」、`中文` 命中「国内」。SVM 摘要原写「结构风险最小化」→ 被推成 `安全` 标签；WaveNet 原写「中文语音合成」→ 被推成 `国内` 标签。两条都改成不含雷区的等价表述，然后重导 seed.json 与 api golden。

**被否决的方案**

- *直接采海报的 40 条*：五处年份硬伤 + 零引用，采进来就是给「单一权威来源」制度开后门。
- *补 WABOT-1 / AIBO 凑机器人线*：早稻田域名连接失败、Sony 站点 403，两条都停在「有说法、无落地页」。
- *补 TensorFlow 2015 开源*：`blog.google` 的相关 URL 404、GitHub API 查 `v0.5.0` release 也是 404，官方口径找不到稳定页。
- *给 `kind` 顺手加「按时代筛选」的交互*：当前没有这个需求，`YearScrubber` 已经是年份级入口；先只做标注，把交互留给真的有反馈时再做。
- *为了不改 benchmark 而把 DQN 的 importance 压到 84*：那是让数据迁就门禁。正确顺序是登记基准条目，让门禁反映「这条重要、且该被覆盖」。
- *升 `SEED_VERSION` 两次（补录一次、改摘要一次）*：该版本尚未对外发布，同一批未发布内容内多次修改不需要额外升版，否则只是给 `sync_state.seed_version` 制造噪声。

```
1974/1978      → winter     1974 第一次低谷：经费收缩
1980/1982/1986 → boom       1980 专家系统繁荣
1987/1989/1992 → winter     1987 第二次低谷：专家系统退潮
1995           → boom       1993 统计学习与概率方法
1997/2011      → boom       1997 统计学习与算力
```

**低谷段的视觉只加两处，不做整体换肤。** 表头标签加「低谷 · 」前缀、侧栏卡片标题改「低谷期」并把顶边框换成虚线（`--rule-strong`）。时间线主体、条目样式、年份索引一概不动——分段是给读者提供上下文，不是把两段历史涂成灰色。

**重启上线用 `app.cli seed`，不跑整轮同步。** 完整 `sync` 会把 24 条候选送进五席评审（真实 token 成本），而本轮的诉求只是把 10 条种子写进库。`python -m app.cli seed` 幂等、只插种子，实测 `seed rows inserted: 10`。顺序是「停 API → 插种子 → 起 API」，避免在服务运行时写库。

## 十一、总结

v0.3.1 结束时，时间线是一份「最近五年很密、前七十年很稀」的档案：148 条里 95 条在 2020 年之后，1980–1996 只有 5 条，而侧栏在 1950 到 1996 之间任何一年都告诉你同一句「在两次热潮与寒冬之间前行」。这次做了两件事把这个偏斜掰回来——先是按一张外源海报的缺口清单补了 10 条经典期条目，每条都落到 DOI 或官方页上，顺带把 `xcon-1980` 这个长期存在的基准缺口补上（覆盖率 89.8%，gaps 14 → 13）；再把 1950–1996 拆成五段，让 1974 与 1987 两个低谷在表头、侧栏、边框样式上都留下痕迹。

更值得记的是过程里的两个教训。海报那种「看起来很全」的资料，五处年份经不起核对，说明缺口清单可以借、事实不能借。以及两条摘要在门禁全绿的情况下带着错标签进了 seed.json——`风险` 推成「安全」、`中文` 推成「国内」——这类错误只有把生成物重新读一遍才看得见，而不是靠 `check:*` 变绿。
