## 📝 摘要

**本文结构概览**：
先确认 1986 年反向传播给出了什么（多层可训练）；
再指出一个常被忽略的事实——**1998 年 LeNet-5 已经把今天视觉的一切要素做对了**；
然后拆"为什么没爆"的三缺：数据规模、算力成本、一个公开可比的高难度擂台；
中间插入一段常被跳过的历史：SVM 与统计学习在这些年里占了主流；
最后到 2006（深度信念网络）与 2009（ImageNet），看 2012 的三件事如何凑齐。

**背景**：
"1986 有反向传播，2012 才爆发"是深度学习史的标准叙事。但标准叙事常常跳过中间二十六年，
导致一个错觉：中间什么都没发生。实际上中间发生了很多事，只是不在同一条线上。

**核心问题**：
一个方法从"能跑"到"值得押注"，中间要等什么？

**解决方案**：
把拐点拆成三个独立变量：**算法、数据、算力**。三者任何一项不到位，拐点都不会发生；
而三者到位的顺序，决定了这二十六年里谁在台上、谁在台下。

**关键成果**（按生产库条目实测）：

- 1986 反向传播论文发表于《Nature》，是本文的算法起点
- 1989 年 LeCun 已用卷积网络识别手写邮编；1998 年 LeNet-5 与 MNIST 确立训练范式
- 1995 年 SVM 提出后，在此后十余年成为小样本分类主力，直到深度学习兴起才让出位置（档案原文表述）
- 2006 年深度信念网络用逐层预训练让深层网络重新可训练，被视为深度学习复兴起点
- 2009 年 ImageNet 数据集论文发表，为 2012 的突破提供数据基础
- 2012 年 AlexNet 用 GPU + ReLU + Dropout 以显著优势赢得竞赛（论文摘要报告 top-5 误差 15.3%，第二名 26.2%）

**适合读者**：想理解"技术拐点为什么发生在那一年"的工程师、正在做技术选型的人、AI 课程的教学者

**阅读时长**：约 15 分钟

**关键词**：`反向传播`、`LeNet`、`AlexNet`、`ImageNet`、`SVM`、`技术拐点`

## 一、先说结论

1986 年给的是"可以训练多层网络"，2012 年给的是"训练多层网络值得"。

中间差的不是方法，是三样东西的**同时到位**：

1. **数据**：从几千张手写数字，到一千多万张带标注的图片（ImageNet）
2. **算力**：从 CPU 到 GPU，同样的训练任务成本降了一到两个数量级
3. **擂台**：一个公开、统一、足够难、每年比一次的评测（ILSVRC）

而在这三样凑齐之前，有一个更强的对手占着位置：**SVM 与统计学习**。它样本效率高、理论完备、调参简单，在 1995 到 2010 年之间是更理性的选择。

所以那二十六年不是空白，是**另一条路线在台前的二十六年**。

## 二、1986：算法这一环补齐了

1986 年 10 月，Rumelhart、Hinton 与 Williams 在《Nature》发表反向传播论文，证明多层网络可以通过误差反传学习内部表示。

它解决的正是第 03 篇留下的那个问题：多层怎么训。

用一句话说清它的机制：

```
前向：输入 → 逐层变换 → 输出
误差：输出与目标的差
反向：把误差按链式法则逐层往回传，算出每个权重该改多少
更新：按梯度方向调权重，重复
```

这个循环的关键在于——**隐藏层没有标签，但它的误差可以从输出层反推出来**。1969 年那本书卡住的地方，是"隐藏层没有监督信号"；1986 年给出的答案是"监督信号可以反传"。

方法到位了。但到位不等于好用。

把它的数学剥到最薄，就是一个 2-2-1 的网络加一次链式法则。下面这 25 行就是 1986 年那篇论文的全部核心（训练 XOR，能跑通）：

```python
import numpy as np

X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], float)
y = np.array([[0], [1], [1], [0]], float)          # XOR

W1, b1 = np.random.randn(2, 2), np.zeros((1, 2))  # 输入层 -> 隐藏层
W2, b2 = np.random.randn(2, 1), np.zeros((1, 1))  # 隐藏层 -> 输出层
lr = 0.5

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

for _ in range(20000):
    h = sigmoid(X @ W1 + b1)          # 前向：4x2
    o = sigmoid(h @ W2 + b2)          # 前向：4x1

    d_o = (o - y) * o * (1 - o)       # 输出层误差（含 sigmoid 导数）
    d_h = (d_o @ W2.T) * h * (1 - h)  # 关键一步：误差反传到隐藏层

    W2 -= lr * h.T @ d_o
    b2 -= lr * d_o.mean(0, keepdims=True)
    W1 -= lr * X.T @ d_h
    b1 -= lr * d_h.mean(0, keepdims=True)

print((o > 0.5).astype(int).ravel())  # [0 1 1 0]，成功了
```

注意带注释那一行：`d_o @ W2.T`。隐藏层拿不到"标准答案"，它拿到的是"输出层的误差按权重比例分回来的那一部分"。**这就是 1969 年那个死局的出口。**

## 三、1989 到 1998：LeCun 已经把一切都做对了

这是最容易被跳过的一段。

**1989 年**，LeCun 等人把反向传播用于手写邮政编码识别，构建了早期卷积网络。它展示了端到端训练在真实图像任务上的可行性。

**1998 年**，LeNet-5 与 MNIST 发表。卷积、池化、梯度训练的组合理清了现代计算机视觉的基本范式。

请注意这句话的分量：**卷积 + 池化 + 梯度训练**，就是今天所有视觉模型的骨架。它在 1998 年就齐了。

把 LeNet-5 摊开看，结构几乎是现代 CNN 的教科书版：

| 层 | 类型 | 输出尺寸 | 作用 |
|---|---|---|---|
| 输入 | — | 32×32 | 手写数字，比原图大一圈，留出边距 |
| C1 | 卷积 6@5×5 | 6×28×28 | 提取最基础的方向与边缘 |
| S2 | 池化 2×2 | 6×14×14 | 降采样，换取平移鲁棒性 |
| C3 | 卷积 16@5×5 | 16×10×10 | 组合低层特征成局部形状 |
| S4 | 池化 2×2 | 16×5×5 | 再降采样 |
| C5 | 卷积 120@5×5 | 120 | 把特征图压成向量 |
| F6 | 全连接 84 | 84 | 特征重组 |
| 输出 | 全连接 10 | 10 | 对应 0–9 十个类别 |

整个网络约六万个参数。六万——今天一个 embedding 矩阵都比它大四个数量级。但**结构上它已经完备**：局部感受野、权值共享、池化降采样、端到端梯度训练，四件事一件不缺。

那么问题来了：既然 1998 年就有了正确的架构，为什么 2012 年才爆发？

答案是：**1998 年的 LeNet-5 在 32×32 的灰度图上工作得很好，但它撑不起 224×224 的彩色自然图像。**

这不是架构的问题，是容量与成本的问题。层数一多、分辨率一高、类别一多，参数量和计算量就上去了，而当时的 CPU 和当时的数据量都撑不住。

具体差在哪，可以算一笔粗账。卷积的主要计算是乘加：一个 224×224 的输入、64 个通道、3×3 的核，单层就要做上亿次乘加；而当时的 CPU 只有几个到十几个核，GPU 的并行度是它的几十倍到上百倍。**同一份代码，换个硬件就从"要跑一周"变成"一天能跑完"。**

更要紧的是这带来的迭代速度差：一周跑一次实验，一年只能试五十个想法；一天跑一次，一年能试三百多个。研究的产出速度，直接取决于你能试多少次。

## 四、三缺：数据、算力、擂台

把"为什么没爆"拆成三条，每条都有具体的量级差。

**缺一：数据规模差三个数量级**

MNIST 是 7 万张 28×28 的灰度图，10 类。这是"教学数据集"的规模——它足够验证方法，但不足以逼出深层模型的能力。

真正的视觉任务有上千类、上百万张、高分辨率、真实光照。在这种数据上，浅模型的瓶颈是特征表达力，深模型的瓶颈是训练成本。**1998 年的数据量，恰好落在"浅模型够用、深模型不划算"的区间里。**

**缺二：算力成本差一到两个数量级**

卷积网络的主要计算是矩阵乘。用 CPU 训练一个深层卷积网络，时间单位是"周"；用 GPU，时间单位是"天"。

这个差距听起来只是快慢，实际上是**实验迭代次数的差距**。一周跑一次实验，一年只能试五十个想法；一天跑一次，一年能试三百多个。研究的产出速度直接差六倍。

**缺三：没有统一的擂台**

这一点最容易被低估。在 ILSVRC 之前，视觉研究的评测是各自为战：各用各的数据集、各用各的划分、各报各的指标。结果是**方法之间不可比**，进步无法被度量。

2010 年开始的 ILSVRC 改变了这件事：统一数据、统一切分、统一指标、每年一次公开排名。它把"谁更强"变成了一个可验证的问题。

具体来说，它固定了三件事：

- **数据集**：一千个类别、上百万张训练图、五万张验证图，每年同一套；
- **指标**：top-5 错误率——模型给出五个答案，只要包含正确答案就不算错；
- **赛制**：每年一次公开提交，结果统一公布。

这三条凑在一起，产生了一个副作用：**它逼所有人把工程细节写进论文**。因为要复现别人的分数，你必须知道他用了几张卡、训了多久、怎么做的数据增强。

第 02 篇讲过的规律在这里又出现了一次：**看得见收益的地方，资源才会流过去**。擂台让收益可见。

## 五、被跳过的那段：SVM 占了中间十年

如果只读深度学习史，会觉得 1990 年代是"等待期"。但从当时的理性选择看，那十年属于另一条路线。

1995 年，Cortes 与 Vapnik 提出支持向量机，用最大间隔与核技巧把线性分类器扩展到非线性问题，并在统计学习理论框架下给出可操作的求解方法。

它的三个优势，在当时几乎是决定性的：

| 维度 | SVM | 神经网络（1995 年视角） |
|---|---|---|
| 样本效率 | 小样本表现好 | 需要大量数据 |
| 理论保证 | 有泛化界 | 缺乏可靠理论 |
| 调参难度 | 核函数 + 正则参数 | 层数、学习率、初始化、早停…… |
| 可解释性 | 支持向量可分析 | 黑箱 |

**在数据少、算力贵、理论要求高的年代，SVM 是更理性的选择。** 这不是"学术界保守"，这是在当时的约束下做对了。

举个具体的判断题：2005 年，你要做一个手写数字识别系统，手上有一万张标注图，只有 CPU，交付期三个月。你选哪个？

- 选神经网络：需要调层数、学习率、初始化，没有可靠的泛化保证，训练慢，出了效果不好也说不清为什么；
- 选 SVM：核函数选 RBF，正则参数网格搜索，两三天能出可用结果，还有泛化界可以写进报告。

**在那个约束组合下，SVM 不是"退而求其次"，是正解。** 这也是为什么 2012 年之后 SVM 并没有"消失"——它在小样本、高维、强可解释的场景里仍然是好工具，只是不再是唯一答案。

顺带说 1997 年的 LSTM：Hochreiter 与 Schmidhuber 用门控机制缓解循环网络的梯度消失问题。它在此后近二十年成为序列建模的主力结构——这是"神经网络在寒冬里仍然产出了能用的东西"的典型例子。

## 六、2006 与 2009：最后两块砖

**2006 年**，Hinton 与 Salakhutdinov 在《Science》展示深层信念网络的逐层预训练方法，让深层网络重新变得可训练。这通常被视为深度学习复兴的起点。

它的意义是心理上的：**"深"不再是负担**。逐层预训练给了深层网络一个可行的初始化路径，即使后来大家改用更好的初始化与归一化，这条消息也改变了研究者的预期。

**2009 年**，李飞飞团队发表 ImageNet 数据集论文，构建覆盖两万类别的标注图像库。

它的意义是结构上的：**数据从"自己攒"变成"公共基础设施"**。这一条比任何算法都重要，因为它把一个私人成本变成了公共品。

## 七、2012：三件事同时到位

2012 年，Krizhevsky、Sutskever 与 Hinton 的 AlexNet 以显著优势赢得 ImageNet 竞赛。它用了三样东西：GPU 训练、ReLU 激活、Dropout 正则。

论文摘要报告 top-5 误差 15.3%，第二名 26.2%——**差距超过十个百分点**。这不是"略好"，是"换了一条曲线"。

它用到的三样工程技巧，各自解决一个具体痛点：

| 技巧 | 解决的问题 | 为什么在当时关键 |
|---|---|---|
| GPU 训练 | 训练太慢 | 把实验周期从周降到天，迭代次数翻几倍 |
| ReLU 激活 | 深层饱和导致梯度消失 | sigmoid/tanh 在深层容易饱和，ReLU 只在负半轴截断，梯度直通 |
| Dropout | 参数多、数据相对少导致过拟合 | 随机丢弃一部分神经元，逼网络学冗余表示 |

三样都不算"新算法"——GPU 是硬件，ReLU 早被提过，Dropout 是正则化技巧。但**它们组合起来，把"深层网络训得动、训得准"这件事从可能变成了稳定**。

三件事在这一年凑齐：

```
算法：反向传播（1986）+ 卷积（1989/1998）+ ReLU/Dropout（2012 前后的工程技巧）
数据：ImageNet（2009），一千多万张带标注图片
算力：GPU（消费级显卡即可起步）
```

少任何一件，AlexNet 都不会发生。1986 年有算法没数据没算力；1998 年有架构没数据没算力；2009 年有数据没算力（或者说，没人相信算力值得投）；2012 年三样齐了。

## 八、这二十六年教给我们的事

**第一，方法的领先不等于路线的领先。** 反向传播 1986 年就领先了，但路线要到 2012 年才领先。中间是约束条件在决定谁上台。

**第二，拐点常常是"旧事变便宜"。** 2012 年没有发明新算法，是三件旧东西同时降到了可承受的价格。判断一个技术会不会爆发，看它的三个成本项什么时候同时下降，比看论文数量更准。

**第三，被跳过的竞争者值得记住。** SVM 不是"失败者"，它在自己的约束下是最优解。今天的大模型也一样——它在数据多、算力足的场景赢，但在小样本、强可解释、低功耗的场景，经典方法仍然更合适。

## 九、总结

**三个关键点**：

1. **1986 给了方法，1998 给了架构，2012 给了条件**。三者不是同一年的事。
2. **中间二十六年属于 SVM**。它是那个约束下的理性选择，不是保守派的错误。
3. **拐点的公式是三件事同时到位**：算法、数据、算力，再加一个让收益可见的擂台。

**一个公式**：

```
技术爆发 = 算法就绪 × 数据就绪 × 算力就绪 × 收益可见
```

四个因子相乘，任何一个为零，结果就是零。这也解释了为什么"某方法明明更好却没人用"——另外三个因子还是零。
