## 📝 摘要

**本文结构概览**：
从一个常见的误解入手——"AI 从 1956 年才开始"；然后拆开 1912 年那台象棋自动机到底能做什么、
不能做什么；接着讲它的作者 Torres Quevedo 还提出过什么（模拟计算、浮点运算的设计思路）；
再跳到 1936 年，看图灵如何用一台假想机器定义"可计算"；最后解释为什么"自动化"这条线会比"计算"早整整一代人。

**背景**：
这个档案里最早的一条是 1912 年。常有读者问：一台机械装置凭什么算 AI 史？这篇就是回答。

**核心问题**：
"机器替人做事"与"机器能不能计算"，是同一个问题的两个阶段，还是两条独立的线？

**解决方案**：
把它们拆成三条线看——机械自动化（1912）、逻辑与器件的对应（1938）、可计算性的形式定义（1936）。
三条线的交汇点，才是"电子计算机"真正诞生的地方。

**关键成果**（按生产库条目实测）：

- 1912 年的 El Ajedrecista 能机械识别棋子位置并完成残局将杀，**不含程序**
- 图灵 1936 年论文有 DOI 可查（`10.1112/plms/s2-42.1.230`），是本文唯一的一手文献
- 1912 这一条在档案里被标为 `single`（单一来源），是全站证据最薄的一档
- 与 ENIAC（1946）相距 **34 年**；与图灵机论文（1936）相距 **24 年**

**适合读者**：对"AI 从哪来"感兴趣的工程师、需要讲解科技史的教师、喜欢考据细节的读者

**阅读时长**：约 12 分钟

**关键词**：`AI 起源`、`El Ajedrecista`、`Torres Quevedo`、`图灵机`、`可计算性`、`史料分级`

## 一、先说结论

1912 年，西班牙工程师 Leonardo Torres Quevedo 做出 El Ajedrecista：一台能自动走残局的机器。它用机械装置识别棋子位置，然后机械地走完一个残局并完成将杀。

它没有程序，没有电子元件，也没有"学习"。但它完成了一件在当时看来属于"思考"的事——**在一个封闭规则里做出正确判断**。

二十四年后（1936），图灵才用纸带机器定义了什么叫"可计算"；三十四年后（1946），ENIAC 才让电子计算成为工程现实。

所以答案是：**"机器替人做事"比"机器能不能算"早了一代人**。这两条线不是同一个问题的两个阶段，它们从不同的地方出发，在 20 世纪中叶才汇合。

## 二、1912 年那台机器，到底能做什么

先把边界划清楚，避免把它神化。

**它能做的**：

- 在一盘已经进行到特定残局（王 + 车 对 王）的棋局里，识别棋子大概位置
- 按机械规则移动自己的车，把对方的王逼到棋盘边缘
- 完成将杀，并在违规走子时给出信号

**它不能做的**：

- 不能从开局下起，只处理残局
- 不能学习，规则是机械设计死的
- 不能处理任意棋局，只对特定子力组合有效

这一点很关键：**它是专用机器，不是通用机器**。用今天的说法，它是一个硬编码的专家系统，只是实现方式是齿轮、连杆和电磁铁，不是代码。

但即便如此，它的意义仍然成立：在 1912 年，"机器能在一个需要判断的领域里替代人"这件事，第一次被做出来了。

## 三、Torres Quevedo 的两条线

Torres Quevedo 常被当成"造了个下棋机器人的工程师"，其实他做的是两件事。

**第一条线：机械自动化。** El Ajedrecista 属于这条线。它的思路是——把一类判断拆成机械动作，用物理结构去执行。这条线后来通向工业机器人（1961 年 Unimate 进通用汽车产线）、通向自动控制。

**第二条线：模拟计算。** 他还设计过模拟计算装置，并提出过浮点运算的设计思路。这条线通向"用物理量表示数值，用结构完成运算"。

第二条线更接近"计算机"，但在 1912 年它没有走通——因为模拟计算精度有限、难以级联，最后是数字电路赢了。

**模拟计算为什么输，值得说清楚**，因为它的失败原因和今天很多技术选择的失败原因是同一类：

| 问题 | 模拟计算的处境 | 数字电路的处境 |
|---|---|---|
| 误差 | 每一级都引入噪声，级联后累积 | 每级重新整形，误差不累积 |
| 复用 | 一个装置只算一种运算 | 同一套门电路可组合出任意逻辑 |
| 存储 | 电荷会泄漏，状态会漂移 | 状态是离散的，要么 0 要么 1 |
| 设计 | 靠物理结构，改一次重做一次 | 靠逻辑设计，改一次改图纸 |

最关键的是第一行和第三行：**模拟信号会衰减，数字信号会再生**。一个信号传得远一点就模糊了，另一个传多远都能恢复成标准电平。这个差别看起来小，却决定了哪种技术能被级联成大型系统。

这也是 Torres Quevedo 的悲剧之处：他在两条线上都看到了方向，但第二条线要等器件成熟。**先驱常常不是想法错了，是器件还没来。**

这里有个值得记住的教训：**同一个人的两条技术路线，一条成了工业基础，一条成了历史注脚**。技术史里"正确的方向"常常不是当时看起来最先进的那个，而是后来生态最容易长起来的那个。

再补一句：Torres Quevedo 在 1912 年之后还做过遥控装置（远距离操纵船只），这些工作属于"自动化"这条线的延长。它们的共同点是——**把人的判断替换成机械规则**，而不是让机器自己形成判断。这条线一直到 1961 年 Unimate 进通用汽车产线才真正产业化，中间隔了半个世纪。

## 四、1936：图灵给"可计算"划了一条线

跳到 1936 年。图灵在《On Computable Numbers》里做了一件很抽象的事：

他设想一台机器，只有三样东西——**一条无限长的纸带、一张状态表、一个读写头**。读写头按状态表在纸带上读写符号，纸带可以无限延伸。

然后他问了一个问题：哪些函数是"能被这样一台机器算出来"的？

这个定义的价值在于，它把"可计算"从一个模糊的直觉，变成了一个**可以证明的边界**。他还顺手证明了停机问题不可判定——不存在一个通用程序，能判断任意程序会不会停。

一句话概括这两件事的分工：

| 年份 | 谁 | 做了什么 | 解决了什么 |
|---|---|---|---|
| 1912 | Torres Quevedo | 用机械装置完成残局将杀 | 机器能不能**做**一件事 |
| 1936 | Turing | 用纸带机器定义可计算 | 什么叫**算**得出来 |
| 1938 | Shannon | 用布尔代数描述开关电路 | 逻辑能不能**落到器件上** |

三条线在这里交汇：**自动化提供"做"的传统，可计算性提供"算"的定义，开关电路提供"实现"的载体**。三者凑齐，电子计算机才有可能。

顺带说一句 1938 年香农那篇：他在 MIT 的学位论文里证明继电器与开关电路可以用布尔代数描述，并给出电路化简方法。这篇的重要性常被低估——没有它，"逻辑"就只是纸上的符号，落不到电路上。

它具体做对了两件事：

1. **把"真/假"映射到"通/断"**。布尔的 AND、OR、NOT 分别对应串联、并联、常闭触点。于是逻辑表达式可以直接画成电路图。
2. **给了化简方法**。同一个逻辑函数有多种电路实现，布尔代数能找出用器件最少的那个——这在继电器时代是直接的省钱。

这两件事合起来，把电路设计从"手艺"变成了"工程"。1938 年他 22 岁，论文是硕士论文。

## 五、为什么"自动化"会早于"计算"

这个问题看起来奇怪：既然计算更难，为什么自动化先出现？

原因有三层：

1. **自动化的门槛是机械精度，计算的门槛是理论**。造一台能识别棋子、能走车的机器，需要的是加工精度和巧妙的机械设计；这件事 19 世纪的工业能力已经够用。而"什么叫可计算"必须先有形式逻辑的基础，那是 1930 年代的事。
2. **自动化处理的是封闭任务，计算要处理开放问题**。残局将杀的子力组合是有限的，机械可以穷举；而"任意函数"是无限的，必须先有定义才能谈边界。
3. **自动化的收益立刻可见，计算的收益要等几十年**。一台会下棋的机器能上报纸；一台纸带机器只能上论文。资源永远先流向看得见的地方。
4. **展示比论证更容易传播**。El Ajedrecista 在巴黎和西班牙的展览上被围观，报纸报道它"会思考"；图灵的论文只有少数同行能读。**技术的传播速度取决于它能不能被看见，而不取决于它有多深。**

第四条在今天仍然成立。每年都有大量"演示视频"比论文传播得广，而其中相当一部分在真实场景里跑不动。判断一个技术时，先问一句：**我看到的是能力，还是一场演示？**

这个规律在后面还会反复出现。2012 年 AlexNet 引爆，不是因为反向传播是新的（1986 就有了），而是因为算力和数据终于便宜到"看得见收益"。**技术史的时间差，大多来自"门槛类型"的差异。**

## 六、为什么这一条只有一条来源

我在第 01 篇说过，档案给每条打可信度：`verified`、`likely`、`single`。1912 这条是 `single`——它只有一个来源，一个维基百科条目。

这不是偷懒。1912 年的原始材料有几类现实困难：

- Torres Quevedo 的原始论文与设计图是西班牙语，数字化程度低；
- 那台机器本身在西班牙的博物馆里，公开的工程图纸很少；
- 二手转述很多，但大多互相抄，不构成独立来源。

所以我把它标成 `single`，并且在正文里只写条目摘要能支撑的部分：机械识别棋子位置、走完残局并完成将杀、靠电气与机械装置、他还提出过模拟计算与浮点运算的设计。

**我没有写"三步内完成将杀"这种细节**——虽然流传很广，但一条来源支撑不住它。

如果你也想自己核实这条，可以按这个顺序查：

1. **先看条目引用的那一手页面**（英文维基条目），翻到它的"References"，看它引的是哪本书或哪篇论文；
2. **再找原始材料**：Torres Quevedo 的原始论述多为西班牙语，收录在马德里理工大学的档案与早期期刊里，数字化程度低；
3. **最后看实物**：那台机器现在在西班牙的博物馆有藏品记录，藏品说明通常会写制造年份与功能范围——这是最硬的一类证据。

我为什么停在"条目摘要"这一层？因为再往前一步需要读西班牙语档案，而我无法确认自己转述得准确。**宁可少写一句，不写一句查不到的。**

对比一下 1936 那条：它有 DOI，能点开原始论文。同样是"我写的"，两条的证据强度完全不同。这就是要分级的原因。

**全站的 11 条 `single` 长什么样？** 我把它们全列出来，你可以自己看分布：

| 年份 | 条目 |
|---|---|
| 1912 | El Ajedrecista 象棋自动机 |
| 1920 | 恰佩克《R.U.R.》，robot 一词进入语汇 |
| 1931 | 哥德尔不完备定理 |
| 1959 | GPS 通用问题求解器 |
| 1959 | MIT 人工智能实验室成立 |
| 1965 | Dendral 启动，专家系统路线成形 |
| 1969 | Shakey 移动机器人 |
| 1972 | Prolog 设计完成 |
| 1974 | MYCIN 用规则诊断血液感染 |
| 1982 | 日本启动第五代计算机计划 |
| 2002 | iRobot Roomba 上市 |

**十一条里有九条在 1982 年以前。** 这个分布不是巧合：

- 早期事件的一手材料多是机构档案、专著与纸质期刊，数字化程度低，常只能找到"百科条目"这一层；
- 后期事件（尤其是 2018 年以后）同时有官方博客、arXiv、模型目录三重信号，想只剩一个来源都难。

所以 `single` 这个标不是"没查"，是"公开可查的只有一层"。它的正确用法是：**把这条当待核实的线索，而不是定论。**

**三个等级，按来源家族的数量判**——本站把来源归成官方发布页、arXiv、论文库、模型目录、媒体、百科几个家族，同一家族发十篇也只算一族：

| 等级 | 判定条件 | 写文章时怎么说 |
|---|---|---|
| `verified` | 两个及以上家族各自报道过 | 可直接引，并给出其中一个出处 |
| `likely` | 只有一个家族，但属主源（官方 / arXiv / 论文库 / 模型目录）且重要度 ≥ 55 | 写"据 X 报道"，不写成定论 |
| `single` | 其余：单一弱来源，或主源但重要度不足 | 明确写"仅一条来源，待核" |

**这样判会出现反直觉的结果，而那正是它可信的原因**：本文附录里 1938 年香农那条，来源数是 2，却仍然只是 `likely`——因为那两个来源都属于"论文"这一族。数来源个数很容易，也很容易被骗；数家族才真能防住"同一篇通稿被十家转载"。

这套分级的价值不在"我有多严谨"，而在**把不确定性摆在读者能看见的地方**。读者据此决定要不要再查一次。

## 七、总结

**三个关键点**：

1. **1912 的机器是专用机器**，只解残局，不学习，但它是"机器替代判断"的第一个实物证据。
2. **1936 的图灵机不是一台机器，是一个定义**。它的贡献不是造出什么，而是说清了"算得出来"的边界。
3. **自动化早于计算，是因为门槛类型不同**：机械精度 vs 形式化理论。这个规律在 2012、2022 又重演了两次。

**一个公式**：

```
能替代人做的事 = 封闭规则 + 可执行结构 + 明确的结束条件
```

1912 年满足这三条，所以它成功了；1956 年的乐观预期不满足第一条（开放世界），所以它落空了。

**下一篇**：《一本书让神经网络冷了十年？1969 年那本书其实只证明了"单层不够用"》——那本书到底证了什么，为什么它被误传了半个世纪。

**思考题**：

1. 如果 El Ajedrecista 当年就能处理任意棋局，AI 史会不会提前四十年？
2. 今天有哪些"专用机器"正在被误认为"通用智能"？
