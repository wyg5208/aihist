## 📝 摘要

**本文结构概览**：
先复盘连接主义的第一次热潮（1943 形式神经元 → 1949 赫布规则 → 1958 感知机）；
再逐条拆 1969 年《Perceptrons》**证明的**与**没证明的**；
然后追踪一句话如何从"单层不够"变成"神经网络不行"；
接着看 1986 年的反向传播如何回答了同一问题；
最后给出一套读"否定性论文"的方法，以及这次误读真正的代价。

**背景**：
"明斯基的书让神经网络冷了十年"是中文技术圈流传最广的一句 AI 史断言。这句话有一半是真的，
另一半是转述中把**限定条件**丢掉了。这篇就是把限定条件捡回来。

**核心问题**：
一个正确的技术结论，为什么会变成一个错误的历史判断？中间丢了什么？

**解决方案**：
把一个结论拆成四件套——**对象、条件、结论、边界**——分别核对。
1969 年那本书的对象是"单层"、条件是可训练权重只有一层、结论是表达力不足、边界是多层不在此列。
四件套齐全时它是硬结论；丢了"单层"两个字，它就成了一句口号。

**关键成果**（按生产库条目实测）：

- 1943 年 McCulloch–Pitts 神经元：带阈值的逻辑单元，可组合计算逻辑函数（`verified`，两个来源）
- 1949 年赫布规则：同时激活的神经元连接会增强（`verified`，两个来源）
- 1958 年感知机：可学习权重的模式分类器，附硬件 Mark I（`likely`）
- 1969 年《Perceptrons》：严格分析**单层**感知机无法表示异或等非线性函数（`likely`）
- 1986 年反向传播：多层网络可通过误差反传学习内部表示（`likely`）

**适合读者**：正在学神经网络基础的人、需要讲清"为什么要有隐藏层"的教师、对技术史传播感兴趣的读者

**阅读时长**：约 13 分钟

**关键词**：`感知机`、`异或问题`、`Perceptrons`、`明斯基`、`反向传播`、`技术史误读`

## 一、先说结论

1969 年那本书证明的是：**只有一层可训练权重的感知机，表达力有硬上限，连异或都做不到**。

它没有证明：多层网络没用、神经网络这条路走不通、连接主义该退场。

前一句是数学结论，后一句是历史判断。中间隔着一个当时无解的技术难题——**多层网络怎么训练**。这个问题要到 1986 年反向传播论文发表才有公认答案。

所以更准确的说法是：**不是那本书杀死了神经网络，是"多层不可训练"这个事实让它在十七年里没有出路。**

## 二、第一次热潮是怎么起来的

连接主义不是从 1958 年突然开始的，它有三块地基。

**1943 · 神经元可以是个逻辑单元**

McCulloch 与 Pitts 把神经元抽象成带阈值的逻辑单元，并证明这类单元组成的网络可以计算逻辑函数。

这一步的意义：**神经生理学和符号逻辑第一次接上了**。神经元不再只是生物学的对象，它可以被当成计算元件来分析。

**1949 · 学习可以是权重的变化**

Hebb 在《行为的组织》里提出："同时激活的神经元，连接会增强。"

这一步的意义：**学习有了机制假设**。如果知识存在连接强度里，那"学习"就等于"改权重"，而改权重是可以算的。

**1958 · 学习可以被工程实现**

Rosenblatt 提出感知机：用可学习的权重完成模式分类，并做出硬件实现 Mark I。

这一步的意义：它把前两块地基拼成了一个能跑的东西。**"从数据里学"不再只是设想，而是有一台机器在那里分类图像。**

一个细节常被忽略：感知机当时的宣传力度非常大，媒体把它描述成"会思考的机器"。这种宣传反过来抬高了后来被否证时的落差——这也是"一本书杀死一个领域"这类叙事容易流行的心理基础。

感知机的学习规则本身非常简单，五行就能写完：

```python
# Rosenblatt 感知机学习规则（1958 年的数学）
w = [0.0] * n
b = 0.0
for epoch in range(EPOCHS):
    for x, y in data:
        y_hat = 1 if sum(wi * xi for wi, xi in zip(w, x)) + b > 0 else 0
        err = y - y_hat
        w = [wi + lr * err * xi for wi, xi in zip(w, x)]
        b += lr * err
```

就这么多。它有个漂亮的性质：**只要数据线性可分，这个循环一定在有限步内收敛**。

所以 1969 年那本书否定的不是这个算法，而是它的**适用范围**——算法没错，模型容量不够。这个区分很重要：前者说"方法错了"，后者说"工具只适用于某类任务"。

## 三、1969 年那本书，证明的与没证明的

《Perceptrons》由 Minsky 与 Papert 合著。它的核心工作不是喊口号，是**严格分析一类模型的表达能力**。

**它证明的**：

- 单层感知机只能表示线性可分的函数
- 异或（XOR）不是线性可分的，所以单层做不到
- 更一般地，某些需要"整体性质"的判断（比如连通的判定），单层结构无法表达

**它没有证明的**：

- 多层网络表达力不足（恰恰相反，多层能表达异或，这是常识）
- 感知机学习算法本身有问题（算法没错，只是模型容量有限）
- 神经网络研究应该停止

这里必须把"单层"两个字咬死。为什么？因为**当时的感知机就是单层可训练**——隐藏层即使存在，也没有可靠的训练方法。所以"单层不够"在 1969 年等价于"现有可训练模型不够"，这个结论在当时是实的。

书里还有一个常被遗忘的结论，比异或更有杀伤力：

**单层感知机无法判定一个图形是否"连通"。**

这个问题的特殊之处在于：要判断一个图形是否连通，你必须看**整体**；而单层感知机每个输出只依赖局部感受野的加权和。即使把感受野放大到全图，它仍然只能做一次线性划分。

这比异或更能说明问题：异或只是四个点的小例子，容易被当成"特例"；而连通性是**一类需要全局性质的任务**，它指向的是一整类能力的缺失。

但它成立的前提是"可训练"。1986 年反向传播给出了多层可训练的方法，这个前提就失效了。

这本书还有一个方法论上的价值，常被忽略：**它示范了怎样用数学给一个模型划边界。**

它没有说"感知机不好"，它说的是"这类模型能表示的函数集合是这些，不包含那些"。这种写法后来变成了标准——今天你读任何一篇缩放定律、任何一篇能力评估论文，看到的都是同一个结构：

```
在【模型家族】上，给定【数据分布】与【算力预算】，
性能随【规模变量】按【函数形式】变化，
适用区间是【范围】，超出该区间不再成立。
```

半个世纪过去了，技术变了几轮，**"结论必须带条件"这个写法没变**。这也是为什么我在第 01 篇里把它拆成四件套——那四件套就是从这类论文的骨架里抽出来的。

## 四、一句话是怎么变形的

从"单层感知机表达力有上限"到"神经网络不行"，中间大概经历了三次变形：

| 阶段 | 说法 | 丢了什么 |
|---|---|---|
| 原论文 | 单层感知机无法表示某些非线性函数 | 无（四件套齐全） |
| 教科书转述 | 感知机连异或都做不了 | "单层"这个限定 |
| 通俗叙述 | 明斯基证明神经网络没用 | "表达力"被换成"整条路线" |
| 传播结论 | 一本书让神经网络冷了十年 | "证明"被换成"因果" |

每一次变形都不算造假，每一次都省掉了一个限定词，最后剩下的那句话读起来很有力、很好记，但已经不对了。

这就是技术史传播的通用损耗机制：**限定词在传播中总是最先被删掉的部分**，因为它让句子变长、变弱、变得不那么像结论。

这种损耗有三个稳定的载体，值得单独警惕：

1. **教科书**。教科书要压缩篇幅，"单层感知机表达力有限"会被压成"感知机有局限"，再被压成"早期神经网络失败了"。压缩本身没错，但环节多了就会丢关键条件。
2. **科普书与纪录片**。它们需要一个叙事弧：兴起—衰落—复兴。"一本书导致十年寒冬"比"缺少多层训练方法导致研究转向"更好讲故事。
3. **课程PPT**。一页幻灯片只能放一行结论，那一行通常就是被删光限定词的那句。

三个载体都不是恶意。它们只是在做同一件事：**为了可传播而牺牲了准确。** 意识到这一点，你才能在接受任何结论时多问一句：它原本的限定条件是什么？

## 五、那十七年到底发生了什么

说"冷了十年"其实也不准确。1969 到 1986 之间，连接主义没死，只是不在聚光灯下。

- 1970 年代，反向传播的数学基础在别的名义下被反复提出（自动微分、最优控制里的伴随方法），只是没被用到神经网络上；
- 1982 年 Hopfield 用能量函数描述反馈网络，把神经网络重新接回物理学——这条路径让"网络会收敛"变成可分析的事；
- 1986 年，Rumelhart、Hinton、Williams 在《Nature》发表反向传播论文，多层网络终于可训练。

所以更准确的描述是：**这十七年里，问题一直摆在那里（多层怎么训），只是没有公认解法**。不是没人研究，是研究的收益看不见。

这一点和第 02 篇讲的规律一致：资源流向看得见收益的地方。1969 年之后，符号主义路线（专家系统）收益可见——1980 年 DEC 部署 XCON 配置专家系统，把数千条规则接进真实生产流程，那是能算出钱的。连接主义算不出来，就退到边缘。

## 六、读"否定性论文"的四件套

这次误读给我留下一个可复用的方法。读任何一篇"某方法不行"的论文，都先找四样东西：

```
1. 对象：它说的是哪个具体模型？（单层感知机 / 通用神经网络）
2. 条件：结论在什么前提下成立？（可训练权重只有一层）
3. 结论：它到底证了什么？（表达力上限）
4. 边界：什么情况不在它覆盖范围内？（多层、可训练隐藏层）
```

四件套齐全，结论就可以直接用。缺一件，就只能当"待核实的转述"。

拿这个方法回看今天的论文同样有效。比如缩放定律类的结论，对象是特定架构、条件是特定数据分布、结论是特定区间内的拟合关系、边界是外推范围。丢掉任何一件，就会得到"堆算力一定更强"这种既对又错的判断。

反过来，这四件套也可以用来**检验别人的转述**。听一句结论，问四个问题，缺哪一件，就是哪一件被丢了。三个真实句式：

| 你听到的说法 | 缺的是哪一件 | 补全后应该怎么说 |
|---|---|---|
| "感知机被证明有局限" | 对象 | 单层感知机无法表示异或这类非线性可分函数 |
| "神经网络有过两次寒冬" | 条件 | 两次低潮的成因不同：一次是经费报告与预期落空，一次是专用硬件市场崩掉 |
| "深度学习靠算力堆出来的" | 边界 | 在图像、语音这类有大量标注数据的封闭任务上成立，开放推理另说 |

第二行值得多说一句：把两次低潮合并成一个"寒冬"是最省事的写法，也是最容易误导读者的写法——因为成因完全不同，拿第一次的成因去预测第二次会错得很彻底。

## 七、这次误读真正的代价

代价不是"浪费了十七年"——那十七年里符号主义确实产出了可用的系统（MYCIN、XCON、日本的第五代计划）。

真正的代价是**认知上的**：一代人学会了一句错误的历史，然后又用这句话去判断新事物。

具体表现有三种，今天还在发生：

1. **用一次失败否定一条路线**。1969 年之后有人说"神经网络不行"；2016 年之后有人说"符号方法已死"。两次都是用单点结论否定整条线。
2. **把工程限制当成理论限制**。"多层训不动"是当时的工程限制（缺方法、缺算力），被读成了理论限制（多层没用）。
3. **用因果替代相关**。"书出版后进入低谷"是时间相关，被读成了因果。真正的因果是"缺训练方法 + 缺算力"。

也有一个正面后果值得说：**这次误读把研究者的注意力推向了"表示"而不是"单元"**。既然单层的线性划分不够，那就要么找非线性映射（核方法、多层），要么找更好的表示（特征工程、嵌入式表示）。

后来的两条主线——SVM（1995）与深度学习（2006 之后）——都可以看作对这个问题的两种回答：一个用核函数把数据隐式地映射到高维，一个用多层网络显式地学表示。**同一个洞，两种填法。**

## 八、总结

**三个关键点**：

1. **1969 年的结论是对的，但它的适用对象是"单层"**。多层能表示异或，这是它没有否证的部分。
2. **真正卡住连接主义的是"多层不可训练"**，这个问题由 1986 年的反向传播回答。
3. **限定词是技术结论的骨头**。传播时删掉限定词，剩下的就是口号。

**一个公式**：

```
可用的技术判断 = 对象 + 条件 + 结论 + 边界
```

少一个，就会在十七年后被现实打脸——或者更糟，在十七年里挡住本该发生的事。
