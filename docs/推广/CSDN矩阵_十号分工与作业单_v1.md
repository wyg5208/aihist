## 一、为什么把 CSDN 当主战场（以及这个赌注会怎么输）

**它赢在哪：** 这批平台里只有 CSDN 的正文能被百度稳定收录。知乎、掘金、B 站的搜索都发生在站内，读者得先在这些平台里搜到，才轮到点开你的文章；CSDN 的文章会直接出现在百度结果里，等于借别人的搜索框做分发。对一个**档案类**站点，这比任何一次爆款都值钱——搜索流量是持续的，爆款是一次性的。

**它会怎么输：** 矩阵号最常见的死法不是没人看，是**被平台判定为营销矩阵**。具体三种信号：

1. 十个号发同一篇（原创检测 → 后发的判非原创，权重互相拖累）；
2. 十个号同一台设备、同一个网络、同一时间密集发文（风控画像）；
3. 每篇文末都在导流（"关注公众号""加微信"是最高危动作）。

所以下面两节的全部设计，都是围绕这三条反着来：**按主题分号、按时间错开、只放一条站内链接且不导流**。

## 四、CSDN 写作规范（平台特性，不是通用写作建议）

| 项 | 做法 | 为什么 |
|---|---|---|
| 标题 | 含主关键词 + 一个具体年份或数字，≤ 30 字 | CSDN 的搜索与推荐都吃关键词，标题里没词就等于没发 |
| 摘要/描述 | 前 80 字内出现主关键词 | 会进百度摘要 |
| 结构 | H2 小节 ≥ 5 个，能上表格就上表格 | 长文被切成小节，跳出率低，站内推荐权重更高 |
| 长度 | 1500–3000 字 | 低于 1200 字很难被当成「技术文」推荐 |
| 代码 | 技术向账号必须有可运行片段（卡 7） | CSDN 读者对纯文字长文的容忍度低于知乎 |
| 标签 | 3–5 个，第一个是主关键词 | 标签是站内分发的入口 |
| 专栏 | 每个号建一个同名专栏，所有文章归入 | 专栏页会被反复访问，是「系列感」的载体 |
| 原创声明 | **每篇必勾** | 不勾会被搬运号先抢原创，之后你反而成了转载 |
| 外链 | 全篇只 1 条，放在「参考资料」小节 | 外链越多越容易进审核；一条链接也更容易被点 |
| 封面 | 自定义封面 1200×675，图上带年份数字 | 列表页只有封面能被看见 |
| 结尾 | 不写「关注公众号」「加微信」 | 这是矩阵号被封的头号原因，没有之一 |

## 五、十号风控清单

这一节比选题重要。矩阵的失败几乎都是运营问题，不是内容问题。

1. **账号不要同源登录**：十个号尽量分散在不同设备或不同网络环境；至少做到不同浏览器 profile、不同时间登录。同设备同 IP 连续登录十个号，是最容易被识别的画像。
2. **前 3 篇不挂外链**：新号或长期未登录的号，先发 2–3 篇纯干货养权重，第 4 篇再放 `/go/` 链接。
3. **单号发文频率 ≤ 1 篇/天**，同号两篇间隔 ≥ 2 天。十个号也不要同一天全开。
4. **不复制粘贴同一段**：跨号复用必须重写开头与结构，至少改掉 30% 的句子。原创检测看的是段落相似度。
5. **不导流到私域**：不写公众号、不写微信号、不写「进群」。要引流就引到站点，站点里再谈订阅。
6. **被限流就停，不要申诉式硬刚**：某号阅读量突然归零，停更 7 天，回来后发纯技术文、不带任何链接。连续两篇被限流就该放弃这个号，而不是换号继续同样打法。
7. **不要在文里写「矩阵」「十个号」**：这是自我暴露，也会让读者觉得内容不值钱。

## 六、怎么读数（矩阵版）

只看一个数：**`#/partners` 里各码的 human 点击数**（bot 已被剔除）。

| 观察 | 判读 | 动作 |
|---|---|---|
| 单码 ≥ 10 / 月 | 这个号跑通了 | 加第二轮同主题选题 |
| 单码 3–9 / 月 | 有流量但落地弱 | 先改链接位置（移到「参考资料」首行），再改标题 |
| 单码 < 3 / 月 | 大概率没被收录 | 百度搜标题原文，搜不到就是收录问题，不是内容问题 |
| 十码全部 < 3 | 矩阵整体没进索引 | 停发一周，检查新号是否被限流；不要靠加发文量解决 |
| `csdn01` 占矩阵总量 > 60% | 只有主号在起作用 | 分号选题太泛，往具体技术词收窄 |

**自查收录的笨办法（够用）**：百度搜「标题原文」（加引号），或 `site:blog.csdn.net 关键词`。收录了但没点击 = 标题不吸引人；没收录 = 账号权重或内容重复问题。

**不要看的数**：阅读量、点赞、收藏。CSDN 这几个数可刷、可互赞，用它做决策会把自己带偏。

## 九、这套东西什么时候该改

- **某个号连续 3 篇 human 点击 0**：换主题域，或者弃号。不要在第 4 篇继续赌。
- **矩阵整体 > 50 次/月**：说明搜索路径成立，这时才考虑第 11 个号，且必须先确认现有 10 个号没有互相抢词。
- **两个以上号被限流**：停矩阵，退回单号深度运营。矩阵的价值建立在账号健康上，账号废了数量没意义。
- **知乎 / 掘金某篇带来 > 100 次点击**：说明讨论型平台比搜索型平台更适合当前内容，把预算（时间）往那边挪，CSDN 降到维护节奏（每号每月 1 篇）。
