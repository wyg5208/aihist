AI 纪年 · 首页改版提案 · 2026-10

5 个方向，一份更大气、更好用的首页

针对当前版本的四点不满：配色不够大气、缺少导航与页脚、卡片内标签纵向堆叠浪费空间、订阅与 API 入口藏得太深。5 个方案共用同一套内容与结构改造原则，只换视觉语言与信息密度组织方式。

① 颜色每个方案给出一套完整品牌色（主色 + 辅助色 + 中性纸色），不再是「米色纸 + 一点红」，并明确深色模式对应色。
② 导航与页脚五个方案都补齐：粘性顶栏（Logo / 主导航 / API / 订阅）+ 四栏页脚（浏览、开放、订阅、版权与入口）。
③ 空间利用卡片内「日期 · 类别 · 机构 · 置信度 · 评审分 · 标签」改为一行横排（flex-wrap），摘要压到 2 行，单条高度下降约 30%。
④ 关键入口订阅与 API 在首屏出现两次：顶栏常驻按钮 + 首屏 CTA 区块；页脚与正文尾部再各留一次，形成 4 次触达。

下一步怎么落地

选定方向后，改动集中在 4 个文件

落地步骤

  1. 设计令牌：把选中方案的四层色板写进 globals.css，同时补齐深色模式对应值。
  2. 新增 SiteNav：72px 粘性顶栏，右侧常驻「API 申请 + 订阅更新」，移动端折叠成抽屉。
  3. 改 EventRow：日期列 + 内容列，元信息全部横排、摘要两行截断，展开区保留原有证据结构。
  4. 重写页脚 + 新增 SubscribeCard：四栏页脚带订阅表单，正文尾部再加一条 CTA 带。

五个方案共同的改造清单（可直接落到现有组件）

问题统一处理涉及组件
配色不大气建立「主色 / 强调色 / 纸色 / 线色」四层令牌，主色承担大色块（首屏行动区、页脚、导航选中态），强调色只用于一句话 CTA 与关键数字globals.css 令牌层
缺导航栏72px 粘性顶栏：Logo、主导航（时间轴 / 模型谱系 / 研究 / 引用指南 / 收录标准）、右侧 API 申请 + 订阅更新新增 SiteNav
缺底栏四栏页脚：关于、浏览、开放（API / 下载 / 引用 / 纠错）、订阅表单；底部一行放版权与四个常驻入口重写 footer
标签纵向堆叠EventRow 改为「日期列 + 内容列」，内容列顶部一行横排：类别徽章 · 机构 · 来源数 · 评审分 · 标签；摘要 clamp 两行EventRow / EventDetail
订阅藏得深入口四连：顶栏按钮、首屏 CTA 区块、正文尾部条带、页脚表单；埋点沿用 ?src=nav / hero / band / footerMasthead / footer / 新增 SubscribeCard
静态原型，仅用于视觉方案比对：数据取自 seed.json 的真实条目，链接指向现有接口路径，交互未接入。
